Este workspace ha sido generado con el Arquetipo de Referencia de Frontend.

## Nx / Angular

El equipo de arquitectura pone a disposición de los equipos de desarrollo un conjunto de tecnologías,
herramientas y documentación para desarrollar proyectos frontend basados en **Angular** bajo ciertos
estándares. Se ha optado por una solución monorepo, basada en **NX**, ya que este tipo de solución
permite a los equipos desarrollar y mantener varias aplicaciones y/o librerías dentro del mismo repositorio.
