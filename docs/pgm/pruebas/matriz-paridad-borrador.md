# Matriz de paridad Appian → nueva aplicación (borrador de la sesión coordinadora)

Punto de partida para las 5 sesiones de pruebas (A–E, ramas `devin/pgm-pruebas-*`). Cruza las 190 interfaces SAIL de PGM (`inventario/pantallas-textos-sail.md`) con lo que hoy existe en `pgm-spa`/`pgm-bff`. Se consolida con los informes de cada área en `docs/pgm/pruebas/<ÁREA>/informe.md`.
